<h1 align="center">📱 Notepad App</h1>

## Sobre el proyecto

Una aplicación de bloc de notas para mobile desarrollada utilizando Python y el framework **Kivy**. En lugar de depender de colecciones de alto nivel predeterminadas o bases de datos externas pesadas para la lógica central, esta aplicación implementa **Listas Doblemente Enlazadas** personalizadas desde cero para gestionar el historial de notas, el ordenamiento dinámico y el control de estados.
